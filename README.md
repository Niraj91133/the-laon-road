# VittFin - Premium Loan & Credit Advisory Landing Page

A responsive Next.js landing page for a specialized loan and financial consultancy business.

## Highlights & Features

1. **Clean, Minimalist 60-30-10 Design**:
   - **60%**: Pure white & crisp slate canvas (`#FFFFFF` & subtle card surfaces).
   - **30%**: Deep slate/navy structure & sharp typography (`#090D16` / `#0F172A`).
   - **10%**: Controlled trust accent blue (`#2563EB`) and defense gold honor badge.
   - Zero flashy/decorative fonts: Clean, corporate, legible sans-serif typography.

2. **Specialized Problem Categories Built-In**:
   - **Imperfect / Incomplete Paperwork**: Custom banking surrogate & turnover models (No-ITR, cash salary).
   - **Multiple Running Loans**: Debt consolidation, balance transfer to lower EMI by 35%+, and fresh top-up loans.
   - **Low CIBIL / Dispute Rectification**: Bureau audit, error dispute filing + alternative soft-check NBFC lending.
   - **Indian Armed Forces / Defense Exclusive VIP Desk**: 24-48 hours express sanction, minimal documents, subsidized rate bracket.
   - **Complete Insurance Solutions**: Health, Term Life, Motor, and Loan Suraksha (Credit Shield).
   - **150+ Banks & NBFCs Network**: Direct tie-ups with SBI, HDFC, ICICI, Axis, Bajaj Finserv, Tata Capital, Piramal, etc.

3. **Interactive Tools**:
   - **Instant Loan EMI & Eligibility Estimator** with real-time slider calculations.
   - **Lead Consultation Modal** with automatic WhatsApp link generation.
   - **Floating WhatsApp & Priority Call Action buttons**.
   - **Statutory Financial Disclaimer** for regulatory compliance.

## How to Run Locally

```bash
# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build for Production

```bash
npm run build
npm start
```
